# Joan from Legal — landing page (beta)

A single static page. No build step, no dependencies.

```
index.html            the page (styles and scripts are inline)
assets/joan-logo.svg  logo, also used as the browser-tab icon
```

## Publish on GitHub Pages
1. Upload these files to the root of your repository (keep the `assets` folder).
2. In the repository go to **Settings → Pages**.
3. Under *Build and deployment*, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.
